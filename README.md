Agri-Land-AI(Zarkhez Zameen AI)

Project Overview

Zarkhez Zameen AI is a smart farming application developed using Python and Streamlit. It helps farmers estimate their irrigation needs and make better decisions for their crops.
The application provides weather information, water requirement estimates, farm alerts, and useful farming recommendations. It also allows users to download a report of their farm information.

Features

- Smart Irrigation Calculator: Estimates water requirements based on crop type, farm area, soil type, temperature, and soil moisture.
- Weather Information: Fetches weather data for a selected city.
- Water Usage Chart: Shows a comparison of estimated water requirements.
- Farm Alerts: Provides alerts based on weather and farm conditions.
- Farming Recommendations: Gives simple suggestions to help farmers manage irrigation.
- CSV Report: Allows users to download their farm report.
- Language Option: Supports English and Urdu interface options.

Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Requests
- Open-Meteo Weather API

Installation and Setup

1. Download or clone the project to your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install the required libraries:
   "python -m pip install -r requirements.txt"
5. Run the application:
      "python -m streamlit run app.py"
6. Open the local URL shown in the terminal to use the application.

How to Use

1. Select your preferred language.
2. Enter the farm details, including crop type, area, and soil conditions.
3. Select a city to view weather information.
4. Calculate the estimated irrigation requirement.
5. Review the chart, alerts, and farming recommendations.
6. Download the report if needed.

Purpose

The purpose of this project is to demonstrate how technology can support smart farming by providing useful information about irrigation and weather conditions.

Disclaimer

This project is an educational prototype. Its irrigation calculations are simplified estimates and should not be treated as professional agricultural advice. Farmers should consider local conditions and expert guidance before making irrigation decisions.
